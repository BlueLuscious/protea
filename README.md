# Protea

Protea is a UI component library project in Garden. It aims to provide reusable component
behaviour, accessibility and composition with optional presentation and framework integrations.

## Current status

The repository currently provides project documentation, shared-rule adoption, an ISC licence and
text hygiene configuration. Component contracts, runtime code and product packages have not been
introduced. The selected contributor toolchain is documented but is not yet configured, and there
are no repository installation, build or test commands to run.
